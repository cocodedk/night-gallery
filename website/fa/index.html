همین حالا ببینید

باز کردن گالری

پیکان راست برای کارت بعد، پیکان چپ برای کارت قبل، OK برای مکث.

نصب روی تلویزیون

نصب چهار قدم دارد و هیچ نرم‌افزار خریداری‌شده‌ای لازم نیست.

  1. این مخزن را کلون کنید. git clone https://github.com/cocodedk/night-gallery.git
  2. بررسی‌ها را اجرا کنید. npm run check — همان چهار مرحله‌ای که خود پروژه هم پیش از هر نصب پشت سر می‌گذارد: سینتکس، تست‌های واحد، سازگاری با Chromium 76، و یک تست کامل سرتاسری.
  3. حالت توسعه‌دهنده را روی تلویزیون فعال کنید. پنل اپ‌ها ← عدد 12345 را بزنید ← Developer mode را روشن کنید ← آی‌پی این دستگاه را به‌عنوان host تنظیم کنید ← تلویزیون را دوباره روشن کنید.
  4. نصبش کنید. npm run install-tv — تلویزیون را روی شبکه پیدا می‌کند، ویجت را می‌سازد و امضا می‌کند، و اجرایش می‌کند.

برای پکیج کردن اپ به یک signing profile در Tizen Studio نیاز دارید؛ راهنمای کامل توی فایل README مخزن هست.
