Dansk

Overskud

Literally “surplus”: the spare mental energy to be patient, generous, or playful. You don’t find time for people; you need overskud for them.

Dansk

Pyt

A tiny word for letting small annoyances go. Danish schools even keep a physical pyt-knap to press. Not resignation; a decision that this one is not worth your overskud.

Latin

Festina lente

“Make haste slowly.” Suetonius records it as Augustus’s favourite saying: speed without care is just a faster way to fail.

Chess

Zugzwang

A position where every legal move makes things worse. The obligation to act becomes the losing condition. German for “compulsion to move.”

Thinking

Chesterton’s fence

Never remove a fence until you know why it was put up. Reforms made in ignorance of a rule’s purpose tend to rediscover that purpose the hard way.

This is the app. It looks exactly like this on the wall.

Three functions, always

  • Teach

    A chess puzzle to sit with between tasks, its solution hidden until later. A framed chess position from a famous game, an opening, or an endgame study, its key squares marked in gold. A concept card drawn from a library of 585, spanning fourteen subjects, one at a time.

  • Run in the background

    Nothing to click, nothing that needs an answer. The rotation moves on its own, quietly, whether or not anyone is in the room.

  • Make the room beautiful

    Every card is decor first, lesson second. Between them, slow ambient light lets the room breathe.

Put it on your TV

  1. Clone the repository. git clone https://github.com/cocodedk/night-gallery.git
  2. Run the checks. npm run check: the same syntax, unit, compatibility and end-to-end gates the project runs before any install of its own.
  3. Put the TV in developer mode. Apps panel → type 12345 → toggle Developer mode on → set this machine’s IP as the host → reboot the TV.
  4. Install it. npm run install-tv: finds the TV on the network, packages and signs the widget, installs it, and launches it.

Packaging requires a Tizen Studio signing profile of your own. See the repository README for the full setup.
